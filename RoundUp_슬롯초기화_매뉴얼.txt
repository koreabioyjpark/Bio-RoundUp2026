[언제 사용?]
  - 행사 종료 후 다음 행사를 위해 데이터를 완전히 초기화할 때
  - 테스트 데이터를 모두 지우고 새로 시작할 때
  - 슬롯 구조에 변경사항이 생겨 재생성이 필요할 때


────────────────────────────────────────────────────────────────
[사전 준비물 — RoundUp 폴더에 모두 있어야 함]
────────────────────────────────────────────────────────────────
  ✓ init-slots.js
  ✓ serviceAccountKey.json   (Firebase 비공개 키)
  ✓ package.json
  ✓ node_modules/ 폴더       (npm install 결과물)
  ✓ Node.js 설치 (https://nodejs.org)


────────────────────────────────────────────────────────────────
[STEP 1] Firebase Console에서 기존 데이터 삭제
────────────────────────────────────────────────────────────────

  ① Firebase Console 접속
     https://console.firebase.google.com
     → bio-roundup-2026 프로젝트 선택

  ② Firestore Database 메뉴 클릭

  ③ 'slots' 컬렉션 삭제
     - 'slots' 컬렉션 옆 점 세 개(⋮) 메뉴 클릭
     - "컬렉션 삭제" 클릭
     - 컬렉션 이름 'slots' 직접 입력 후 삭제 확정

  ④ 'applicants' 컬렉션도 삭제 (회원 정보까지 리셋하려면)
     - 위와 동일한 방법으로 'applicants' 컬렉션 삭제


────────────────────────────────────────────────────────────────
[STEP 2] Authentication 사용자 삭제
────────────────────────────────────────────────────────────────

  ① Firebase Console → Authentication 메뉴

  ② '사용자' 탭 클릭

  ③ 사용자 전체 선택 후 일괄 삭제
     (체크박스로 다중 선택 가능)

  ※ 주의: 사용자 삭제 후 같은 이메일로 재가입은 가능하나,
     기존 신청 데이터는 복구되지 않음.


────────────────────────────────────────────────────────────────
[STEP 3] 터미널 열기
────────────────────────────────────────────────────────────────

  ① 윈도우 파일 탐색기에서 RoundUp 폴더 열기

  ② 폴더 주소창 클릭

  ③ 주소창에 'cmd' 입력 후 엔터
     → 명령 프롬프트가 해당 폴더 위치에서 열림


────────────────────────────────────────────────────────────────
[STEP 4] 슬롯 재생성 스크립트 실행
────────────────────────────────────────────────────────────────

  명령어 입력:

      node init-slots.js

  성공 시 출력:

      ✅ 36개 슬롯 초기화 완료!


────────────────────────────────────────────────────────────────
[STEP 5] 확인
────────────────────────────────────────────────────────────────

  ① Firebase Console → Firestore Database
  ② 'slots' 컬렉션이 새로 생성됨
  ③ 36개 문서 (desk1_time1 ~ desk6_time6) 확인


================================================================
  자주 발생하는 오류 및 해결법
================================================================

  ▶ 오류: "Cannot find module 'firebase-admin'"
    원인: firebase-admin 라이브러리 설치 안 됨
    해결: 터미널에서 아래 명령어 실행
          npm install firebase-admin


  ▶ 오류: "Cannot find module './serviceAccountKey.json'"
    원인: 서비스 계정 키 파일이 없음
    해결: Firebase Console
          → 프로젝트 설정 (⚙️)
          → 서비스 계정 탭
          → "새 비공개 키 생성" 클릭
          → 다운로드된 JSON 파일을
            'serviceAccountKey.json'으로 이름 변경
          → RoundUp 폴더에 저장
    ⚠ 이 파일은 절대 GitHub에 올리지 말 것
       (.gitignore에 등록되어 있는지 확인)


  ▶ 오류: "'node'은(는) 내부 또는 외부 명령... 인식되지 않습니다"
    원인: Node.js 미설치 또는 PATH 등록 안 됨
    해결: https://nodejs.org 에서 LTS 버전 다운로드 후 재설치
          설치 후 컴퓨터 재시작


  ▶ 오류: "PERMISSION_DENIED" 또는 권한 오류
    원인: serviceAccountKey.json이 다른 프로젝트의 키
    해결: 현재 사용 중인 Firebase 프로젝트
          (bio-roundup-2026)의 서비스 계정 키로 교체


================================================================
  부분 초기화 (슬롯만 리셋, 회원 정보는 유지)
================================================================

  STEP 1에서 'slots' 컬렉션만 삭제하고 'applicants'는 유지
  → STEP 2 건너뛰기
  → STEP 3, 4 진행

  단, 이 경우 기존 회원의 마이페이지에는
  "신청 내역 없음" 으로 표시됨.

  완전 초기화 후 행사 운영 체크리스트
================================================================

  □ Firestore Database → slots 컬렉션 36개 문서 존재 확인
  □ Firestore Database → applicants 컬렉션 비어있음 확인
  □ Authentication → 사용자 비어있음 확인

  □ Admin 페이지 접속 → 통계 0명 표시 확인
  □ 본인 계정으로 테스트 신청 1건 → 정상 처리 확인
  □ 테스트 신청 삭제 (Firestore Console에서 직접)
